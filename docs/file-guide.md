# File guide

What each file in the React + TypeScript + Vite app is for, built up phase by phase during the
Vue 2 migration. Each phase lists the files it added or changed; read top to bottom for the
full picture.

## Phase 0: Scaffold

Starting point: `npm create vite@latest -- --template react-ts`. The Vue app moved unchanged to
`legacy/`.

### Root config

| File                       | Purpose                                                                   | Origin            |
| -------------------------- | ------------------------------------------------------------------------- | ----------------- |
| `package.json`             | Project manifest: npm scripts and dependencies.                           | Template, changed |
| `package-lock.json`        | Exact installed versions so every install is identical. Generated by npm. | Generated         |
| `index.html`               | The single HTML page; loads `src/main.tsx` into `<div id="root">`.        | Template, changed |
| `vite.config.ts`           | Vite dev server and build settings, plus the Vitest test settings.        | Template, changed |
| `tsconfig.json`            | Root TypeScript config that points to the two below.                      | Template          |
| `tsconfig.app.json`        | TypeScript settings for browser code in `src/` (strict mode on).          | Template, changed |
| `tsconfig.node.json`       | TypeScript settings for Node-side files (`vite.config.ts`).               | Template          |
| `.oxlintrc.json`           | Linter rules (oxlint).                                                    | Template, changed |
| `.prettierrc.json`         | Code formatter settings.                                                  | New               |
| `.prettierignore`          | Folders the formatter skips.                                              | New               |
| `.gitignore`               | Files git never commits (`node_modules`, `dist`, local env files).        | Template          |
| `.env.example`             | Sample env vars; copy to `.env.local` and set `VITE_API_URL`.             | New               |
| `.github/workflows/ci.yml` | CI on every PR: lint, format check, typecheck, tests, build.              | New               |
| `README.md`                | How to install, run and work on the project.                              | Template, changed |

### App code (`src/`)

| File                    | Purpose                                                                    | Origin            |
| ----------------------- | -------------------------------------------------------------------------- | ----------------- |
| `main.tsx`              | Entry point: loads global CSS and renders the router into the page.        | Template, changed |
| `index.css`             | Global styles.                                                             | Template, changed |
| `vite-env.d.ts`         | Types for `import.meta.env` variables.                                     | New               |
| `router.tsx`            | Creates the hash router (`/#/...` URLs, same as the Vue app).              | New               |
| `routes.tsx`            | The route table: every URL and the page it renders.                        | New               |
| `components/Layout.tsx` | Page shell: navbar plus `<Outlet />` where the current page renders.       | New               |
| `pages/Home.tsx`        | Home page with links to each section.                                      | New               |
| `pages/Placeholder.tsx` | Temporary stand-in for pages not ported yet.                               | New               |
| `pages/NotFound.tsx`    | Shown for unknown URLs.                                                    | New               |
| `lib/config.ts`         | Runtime config, e.g. the API base URL.                                     | New               |
| `assets/logo.png`       | Navbar logo, bundled by Vite.                                              | New (from Vue)    |
| `routes.test.tsx`       | Tests that each route renders the right page and highlights the right nav. | New               |
| `test/setup.ts`         | Runs before tests; adds DOM matchers like `toBeInTheDocument()`.           | New               |
